# Andrea Tontini

**Software engineer · From application architecture to hardware interfaces**

I’m interested in how software behaves beyond the happy path: under load, with limited resources, and at the boundary with hardware. Welcome to my GitHub — a collection of open-source contributions, distributed computing examples, and research code.

## About me

My interests span higher-level application development with C# and .NET, software architecture, and embedded systems and firmware. I’m particularly interested in working closer to hardware: industrial automation, end-of-line testing, CAN communication, and hardware/software integration.

I care about reliability, maintainability, and making good use of memory and compute. My public work includes C communication code and R statistical analysis; I’m also exploring Rust developer tooling through contributions to Tokensave.

Beyond code, I contribute articles and help organize events with [Italian Embedded](https://www.italianembedded.com), connecting people interested in embedded systems. I’m also an organizer of [Rust Milano](https://www.meetup.com/rust-language-milan/), the Milan Rust community.

## Featured work

### [Tokensave](https://github.com/atontini/tokensave)

**Rust · MCP · Code intelligence · Resource efficiency**

A local code intelligence server that gives AI coding agents indexed access to symbols and their relationships, reducing repeated source scanning. My fork is used for contributions to [the upstream project](https://github.com/aovestdipaperino/tokensave).

My [upstream pull requests](https://github.com/aovestdipaperino/tokensave/pulls?q=is%3Apr+author%3Aatontini) focus on memory use, resource lifetimes, and branch index management — including bounded worker pools, fewer data copies, and cleanup of native database handles.

### [GPI-2 Neighbor Communication](https://github.com/atontini/gpi2-example)

**C · GPI-2 / GASPI · Distributed memory**

An educational example of array exchange between processes on a periodic two-dimensional grid. It demonstrates registered memory, one-sided notified writes, and synchronization: the mechanics of moving data safely between distributed processes. The communication concepts come from internship work related to my university thesis.

### [ICI-RT-NSCLC](https://github.com/atontini/ICI-RT-NSCLC)

**R · metaSurvival · Jupyter · Statistical analysis**

Research code accompanying a study of immune checkpoint inhibitors and radiotherapy in advanced non-small cell lung cancer. An R script and equivalent R notebook pool overall survival curves from aggregate study data. The repository covers this specific analysis within the wider publication.

### [Personal website](https://github.com/atontini/atontini.github.io)

**Jekyll · HTML · CSS**

My personal homepage and blog, built as a static site with reusable layouts and published through GitHub Pages.
